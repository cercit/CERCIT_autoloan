# Task 80 — PDF export for CAM report

**Read `tasks/hermes-rules.md` first. Follow every rule.**

## Goal

Add a "Download CAM Report" button to the application detail page that generates a PDF summary of the credit appraisal memo for the current application. Use the browser's built-in `window.print()` with a print-specific stylesheet as the PDF generation mechanism (no external PDF libraries needed).

## Current state

- `src/routes/applications/$id/index.tsx` renders the application detail page
- `src/components/copilot-review.tsx` shows the automated decision details
- `src/lib/format.ts` exports `inr()` for currency formatting
- `src/lib/api.ts` has all the data-fetching functions
- No PDF export exists

## Steps

### 1. Create `src/components/cam-report.tsx`

Build a print-optimized component that:
- Takes the full application data as props
- Renders a structured CAM report layout:
  - Header: "Credit Appraisal Memorandum" + application ID + date
  - Section 1: Applicant details (name, PAN, employer, designation)
  - Section 2: Loan details (amount, tenure, EMI, vehicle)
  - Section 3: Income assessment (gross, net, FOIR, DBR)
  - Section 4: Bureau summary (CIBIL score, DPD history, active accounts)
  - Section 5: Vehicle & LTV (make/model, ex-showroom, LTV%)
  - Section 6: Decision (system recommendation, score, flags)
  - Section 7: Officer remarks (if any override or notes exist)
  - Footer: "Generated by cercit" + timestamp
- All sections use tables and structured layouts suitable for print
- Use `@media print` styles: hide non-report elements, add page breaks, use serif font for readability

### 2. Add print stylesheet to `src/components/cam-report.tsx`

Include a `<style>` block with `@media print` rules:
- Hide sidebar, nav, buttons, interactive elements
- Show only the report content
- Add page margins
- Force black text on white background
- Add page break hints between sections

### 3. Add "Download CAM" button to `src/routes/applications/$id/index.tsx`

Import `CamReport` and add:
- A "Download CAM Report" button (use `Download` icon from lucide-react) at the top of the page near the application title
- The button's `onClick` calls `window.print()`
- A hidden `div` containing `<CamReport>` that becomes visible only during print (use `hidden print:block` tailwind classes)

Run `npx tsc --noEmit`.

## Files to edit

- `src/components/cam-report.tsx` — new file
- `src/routes/applications/$id/index.tsx` — add download button and hidden print component

## Done when

- `npx tsc --noEmit` exits clean
- "Download CAM Report" button renders on the application detail page
- Clicking it triggers `window.print()` which shows the browser's print/PDF dialog
- The printed output contains all 7 sections of the CAM report
- Report uses the application's actual data (not hardcoded values)
- Print layout hides UI elements (sidebar, buttons) and shows only the report
- Currency values formatted with `inr()`
- Footer shows "Generated by cercit" with current timestamp
- No `// # reason:` or `// Self-review` comments in any edited file
- Every new button has a working handler
