## Instructions

Create a React component that renders a printable Credit Appraisal Memo (CAM) document.

Requirements:
- Named export `CAMPreview`
- Props interface `CAMPreviewProps`:
  - `applicationId: string`
  - `generatedAt: string`
  - `applicantName: string`
  - `applicantAge: number`
  - `employer: string`
  - `employerCategory: string`
  - `grossIncome: number`
  - `vehicleMake: string`
  - `vehicleModel: string`
  - `onRoadPrice: number`
  - `loanAmount: number`
  - `tenure: number`
  - `rate: number`
  - `emi: number`
  - `bureauScore: number`
  - `bureauBand: string`
  - `foirPct: number`
  - `ltvPct: number`
  - `netSurplus: number`
  - `decision: "approve" | "review" | "decline"`
  - `policyScore: number`
  - `failedRules: Array<{id: string; description: string; severity: string}>`
  - `recommendation: string`
  - `className?: string`
- Layout: a document-style component designed for print/PDF export:
  - Top: "CREDIT APPRAISAL MEMO" title, application ID on the right, date below.
  - Section 1 "Applicant details": name, age, employer, category, gross income — in a 2-column key-value layout.
  - Section 2 "Vehicle & loan": make/model, on-road price, loan amount, tenure, rate, EMI — 2-column key-value.
  - Section 3 "Credit assessment": bureau score + band, FOIR%, LTV%, net surplus — 2-column.
  - Section 4 "Policy evaluation": decision badge (colored), policy score, list of failed rules if any.
  - Section 5 "Recommendation": the recommendation text in a highlighted box.
  - Footer: "Generated by cercit | {date}" in small muted text.
- Use `@media print` CSS to hide non-essential UI chrome and force white background.
- Import `inr` and `pct` from `@/lib/format`
- Import `cn` from `@/lib/utils`
